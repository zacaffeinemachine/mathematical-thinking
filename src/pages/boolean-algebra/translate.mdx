Each problem names a few yes/no letters and then says something about them.
Write the sentence as an equation in those letters. The problems get harder
as you go down the page.

**How to type an answer.** Use the letters, the digits `0` and `1`, `+`,
brackets and `=`. A product can be written with `*` or by putting the letters
side by side, so `(1+a)b + c = 1` and `(1+a)*b + c = 1` are read the same way.
The `+` is the boolean one, so `1+1` is `0`. If a sentence needs two
equations, separate them with a comma.

Any correct equation is accepted, whatever its shape. The box checks whether
your equation holds on exactly the same patterns of the letters as the
sentence does, and tells you only whether it does.
