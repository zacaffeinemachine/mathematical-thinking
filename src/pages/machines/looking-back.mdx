<Problem n={5} title="The beginning meets the end" hard>
Design a machine that accepts exactly the strings of length at least 2 whose
**first** symbol is the same as the **second-to-last** symbol.

So `0100101` is accepted and `0100011` is not. Check both by hand before you
start drawing.

Every string of exactly two symbols is accepted, because in a string of two
symbols the first symbol *is* the second-to-last one. If that surprises you,
it is worth pinning down before you draw anything.

This one needs two quite different kinds of memory at once: something the
machine learns at the very start and must never lose, and a window that keeps
sliding. Say which circles are doing which job.
<Tests accept={["00", "01", "10", "11", "1011", "0100101"]} reject={["", "0", "1", "0110", "1000", "0100011"]} />
</Problem>

<Problem n={6} title="Fourth from the end" hard>
Design a machine that accepts exactly the strings of length at least 4 whose
fourth-to-last symbol is a `1`.

Then answer this, which is the real point of the problem. Going from
*second*-to-last to *third*-to-last to *fourth*-to-last, the number of
circles doubles each time. Say in one sentence why it doubles rather than
going up by one.
<Tests accept={["1000", "1111", "01001", "1100"]} reject={["", "1", "111", "0000", "0100"]} />
</Problem>
