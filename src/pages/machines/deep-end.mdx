<Problem n={1} title="Scattered, not consecutive">
Design a machine that accepts exactly the strings in which you can find a `0`,
then a `1` somewhere after it, then a `0` somewhere after that, then a `1`
somewhere after that. The four symbols need not be next to one another, and
anything at all may sit between them.
<Tests accept={["0101", "010011", "00110101", "1010101", "0011011"]} reject={["", "0011", "0110", "1010", "1111", "01000"]} />
</Problem>
<Problem n={2} title="One rule for each letter" alphabet="{x, y}">
A block is one unbroken stretch of a single letter, taken as long as it will
go. The string `xxyyyxx` is a block of `x` of length 2, then a block of `y` of
length 3, then a block of `x` of length 2.

Design a machine that accepts exactly the strings in which every block of `x`
has even length **and** every block of `y` has odd length. A string with no
blocks of `y` in it meets the second condition, and a string with no blocks of
`x` meets the first.
<Tests accept={["", "y", "xx", "xxy", "yxxy", "yyy", "xxyyyxx"]} reject={["x", "yy", "xyx", "xxyy", "xxxy"]} />
</Problem>
<Problem n={3} title="Two patterns, equally often">
Count how many times `01` appears in the string, counting a fresh appearance
at every position where it fits. Count `10` the same way.

Design a machine that accepts exactly the strings in which the two counts are
equal.
<Tests accept={["", "0", "1", "010", "0110", "1001", "11011"]} reject={["01", "10", "0101", "1100", "0011", "100"]} />
</Problem>
<Problem n={4} title="Even gaps between the ones">
Design a machine that accepts exactly the strings in which every stretch of
`0`s lying **between** two `1`s has even length. A stretch of `0`s before the
first `1`, or after the last `1`, is not between two `1`s and is not
restricted. A string with no `1`s in it is accepted.
<Tests accept={["", "0", "000", "11", "1001", "100001", "0100110"]} reject={["101", "10001", "1101", "01010", "100010"]} />
</Problem>
<Problem n={5} title="Overlaps count">
Count how many times `11` appears in the string, counting a fresh appearance
at every position where it fits. Under that counting `111` contains two of
them and `1111` contains three.

Design a machine that accepts exactly the strings in which that count is even.
<Tests accept={["", "1", "111", "11011", "0000", "1110"]} reject={["11", "1111", "1101", "0110", "0011000"]} />
</Problem>
<Problem n={6} title="The first block and the last" hard>
A block of `1`s is one unbroken stretch of `1`s, taken as long as it will go.
The string `110100111` opens with a block of length 2 and closes with a block
of length 3.

Design a machine that accepts exactly the strings whose first block of `1`s
and last block of `1`s are either both of even length or both of odd length. A
string with only one block of `1`s has that one block as both its first and
its last, so it is accepted, and a string with no `1`s at all is accepted too.
<Tests accept={["", "0", "1", "11", "101", "1001", "11011", "0110", "1010101"]} reject={["1011", "1101", "10011", "111011", "110111"]} />
</Problem>

<Problem n={7} title="Never too close, never too far" hard>
Go through the `1`s in the string from left to right. Between each `1` and the
one after it sits a stretch of `0`s. In `1001` that stretch is two `0`s long,
and in `11` it is empty.

Design a machine that accepts exactly the strings in which every one of those
stretches is 1, 2 or 3 symbols long. A string with fewer than two `1`s has no
such stretch and is accepted.
<Tests accept={["", "0", "1", "101", "1001", "10001", "1010001"]} reject={["11", "1101", "100001", "0110", "1000010001"]} />
</Problem>
<Problem n={8} title="Twice over, without sharing" hard>
Design a machine that accepts exactly the strings that contain two appearances
of `101` which do not overlap, meaning that no symbol of the string is used by
both of them. Note that `10101` contains two appearances of `101`, but they
share the middle `1`, so it must be rejected.
<Tests accept={["101101", "1011101", "1010101", "0101010101"]} reject={["", "101", "10101", "1010", "11011"]} />
</Problem>
<Problem n={9} title="Thirds, one letter or the other" hard>
Design a machine that accepts exactly the strings for which at least one of
these two things is true:

- every block of `1`s has length divisible by 3,
- every block of `0`s has length divisible by 3.

A block is one unbroken stretch of a single symbol, taken as long as it will
go, and a string with no blocks of a given symbol meets that symbol's
condition.
<Tests accept={["", "000", "111", "111000", "0001", "1000"]} reject={["01", "110", "100", "0011", "10101"]} />
</Problem>
<Problem n={10} title="Even blocks, counted in threes" alphabet="{x, y}" hard>
A block of `x` is one unbroken stretch of `x`s, taken as long as it will go.
The `x`s in `xxyxyyx` come in three such stretches, `xx` and `x` and `x`, so
that string has one block of even length and two of odd length.

Design a machine that accepts exactly the strings in which the number of
blocks of `x` of **even** length is a multiple of 3. A string with no blocks
of even length in it has none of them, and zero is a multiple of 3, so it is
accepted.
<Tests accept={["", "y", "x", "xyx", "xxx", "xyxxxyx", "xxyxxyxx"]} reject={["xx", "xxyxx", "xxxx", "xxyy", "xxyxxyxxyxx"]} />
</Problem>
