On this page a number is set on switches, and each switch is worth a fixed
amount. The switch $a_4$ is worth 4, the switch $a_2$ is worth 2, and so on.
The number is the total of the switches that are up. A number set on $n$
switches worth 1, 2, 4, 8, and so on, is an **$n$-bit number**. So a 1-bit
number is 0 or 1, a 2-bit number is one of 0 to 3, and a 3-bit number is one of
0 to 7.

Each bulb is worth the amount written beside it, and a row of bulbs shows the
total of the ones that are lit.
